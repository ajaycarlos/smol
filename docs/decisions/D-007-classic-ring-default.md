# D-007: Classic Ring Default

- **Date**: 2026-10-20
- **Status**: Fixed
- **Canonical Reference**: [DECISIONS.md](../../DECISIONS.md#L13)

## Decision
The **Classic fixed ring** is the default donut layout: 8 segments (20 KB, 50 KB, 100 KB, 200 KB, 500 KB, 1 MB, 2 MB, Custom...). The **Smart ring** is an opt-in choice in Settings.

## Why
Fixed spatial positioning allows users to build muscle memory: dragging slightly up-right always lands on 100 KB regardless of the input file size. The smart ring is available for users who prefer dynamic adaptation based on input file size.
